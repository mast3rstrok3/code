# T3 Code

T3 Code is a web interface for working with coding agents. This context names the project concepts used to describe its workflows and verification artifacts.

## Language

**Workflow smoke test**:
A deliberately small, isolated change used to verify that an automated project workflow traverses its required stages end to end. It is not a user-facing product feature.
_Avoid_: Demo task, fake feature

**Browser Dev Review**:
A browser-based review workflow that evaluates a completed change before it is accepted as ready.
_Avoid_: Code review, visual check
